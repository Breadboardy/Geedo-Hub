# Geedo Hub

This is what every Geedo talks to. It serves animations and firmware updates
over the air, and hosts the Animation Studio.

- **Animation Studio** — https://breadboardy.github.io/Geedo-Hub/studio/
- **Browse animations** — https://breadboardy.github.io/Geedo-Hub/browse.html
- **Unlock a secret code** — https://breadboardy.github.io/Geedo-Hub/unlock.html

Animations made by anyone can end up here and every Geedo in the world will
download them automatically.

The hardware design and firmware source are not public.
