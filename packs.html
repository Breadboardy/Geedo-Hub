How a pack gets to your robot

Free packs

Switched on for everyone. Your Geedo finds them at his next check and downloads them himself. Nothing to do.

Code packs

You get a code like GD-K7X9-PQ4M from a card or a giveaway. Type it on the Redeem page, and Geedo can take it himself from his setup page too.

Codes are safe.

Your code is never saved anywhere on the website. Each code pack is a locked box, and the code you type is the only key that opens it.

That is also why the Redeem page pauses for a second: the lock is built to be slow on purpose, so nobody can guess codes by trying millions of them.
