Export

Two kinds of file. Save in the top bar keeps your project (a .geedo.json) for coming back to; these are for taking it elsewhere.

⬇

The robot's file

A .bin exactly as a Geedo plays it: GDA2, one bit a pixel, frames packed. The Hub and the robots read this format.

⬇

Arduino code

The frames as PROGMEM byte arrays for your own sketch and your own screen.

Try it on a Geedo

Right now a Geedo only plays what is on the Hub: he checks it once a minute and keeps everything on the list. So the way to see your animation on a real Geedo is to publish it. Once a person has approved it, every Geedo, yours included, is doing it within the minute.

Sending an animation straight to your own Geedo over WiFi, before publishing, is coming in a firmware update. Until then you can play it here with Play, or save the robot's own file to keep.

Publish to the Hub

A person looks at every animation before it goes out to the robots, so publishing is two steps: save the file, then hand it in. It takes a minute, and you are told either way.

1

Save the file

Your animation as a .geedo.json file, ready to hand in.

2

Hand it in on GitHub

Opens the submission form with the name filled in. Drop the file you just saved into the box and press Submit. The bot posts a preview within a minute; a person answers usually within a day.

No GitHub account? Post the file in #animations on the Discord and it gets handed in for you. The rules.
