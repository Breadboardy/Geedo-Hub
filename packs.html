How a pack gets to your robot

Public packs

These are on for everyone. Your Geedo finds them at his next check and downloads them himself.

Code packs

You get a code like GD-K7X9-PQ4M from a card or a giveaway. Type it in on the Redeem page and the pack is yours.

Codes are safe.

Your code is never saved anywhere on the website. Each code pack is locked with real encryption, and the code you type is the only key that opens it.

That's also why the Redeem page pauses for a second when you type a code: the lock is built to be slow on purpose, so nobody can guess codes by trying millions of them.
