How it gets to your Geedo

It is already there. Every Geedo checks the Hub once a minute and keeps everything on the list in his own memory, so there is nothing to install and nothing to plug in.

The file

The download is the exact file the robot plays: GDA2, one bit a pixel, frames packed. Handy if you build your own screen, or want to remix it in the Studio.

Remix it

Open in Studio loads these frames into the editor. Change it, give it a new name, publish it, and it goes up with a line saying what it started from.
